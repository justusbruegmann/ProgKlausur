# Interface

> [!info] Kurz erklärt
> Ein **Interface** legt fest, *welche* Methoden eine Klasse anbieten muss (`interface Shape { double area(); }`), ohne Implementierung (bis auf default/static). Klassen implementieren beliebig viele Interfaces mit `implements`. Im Programmentwurf wird fast immer ein Interface verlangt.
