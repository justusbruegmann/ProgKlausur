# Default-Methode

> [!info] Kurz erklärt
> Seit Java 8 können Interfaces Methoden mit Implementierung enthalten (`default void log() { … }`) sowie `static`-Methoden. So lassen sich Interfaces erweitern, ohne bestehende Klassen zu brechen.
