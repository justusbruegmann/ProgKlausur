# Collection API

> [!info] Kurz erklärt
> Das Framework `java.util` mit Interfaces (`Collection`, `List`, `Set`, `Queue`, `Map`) und Implementierungen. Gemeinsame Methoden: `add`, `remove`, `contains`, `size`, `isEmpty`, `iterator`. Speichert nur **Objekte**, daher `List<Integer>` statt `int`.
