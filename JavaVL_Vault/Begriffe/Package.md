# Package

> [!info] Kurz erklärt
> Ein **Package** gruppiert zusammengehörige Klassen in einem Namensraum (`package de.dhbwka.java.exercise;`). Klassen anderer Pakete werden mit `import` verfügbar gemacht. Pakete entsprechen Ordnern im Dateisystem; Namen werden klein und als umgekehrte Domain geschrieben.
