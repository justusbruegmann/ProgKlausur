# Polymorphismus

> [!info] Kurz erklärt
> Eine Variable vom Typ der Oberklasse (oder eines Interfaces) kann Objekte jeder Unterklasse referenzieren; beim Methodenaufruf entscheidet der **Laufzeittyp**, welche Implementierung ausgeführt wird.
