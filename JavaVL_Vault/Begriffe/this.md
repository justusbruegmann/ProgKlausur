# this

> [!info] Kurz erklärt
> `this` verweist auf das aktuelle Objekt, z. B. um Attribute von gleichnamigen Parametern zu unterscheiden (`this.name = name;`). `this(...)` ruft einen anderen Konstruktor auf.
