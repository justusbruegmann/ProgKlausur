# Exception

> [!info] Kurz erklärt
> Fehlerobjekte, die mit `throw` ausgelöst und mit `try { … } catch (Typ e) { … } finally { … }` behandelt werden. **Checked** Exceptions müssen gefangen oder mit `throws` deklariert werden. Basisklasse ist `Throwable` (mit `Exception` und `Error`).
