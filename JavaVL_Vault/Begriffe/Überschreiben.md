# Überschreiben

> [!info] Kurz erklärt
> Eine Unterklasse definiert eine geerbte Methode mit **gleicher Signatur** neu. `@Override` lässt den Compiler das prüfen. Zur Laufzeit wird die Methode des tatsächlichen Objekttyps aufgerufen (dynamisches Binden).
