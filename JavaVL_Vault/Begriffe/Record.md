# Record

> [!info] Kurz erklärt
> Seit Java 16: `record Punkt(int x, int y) {}` erzeugt eine unveränderliche Datenklasse mit Konstruktor, Zugriffsmethoden `x()`/`y()`, `equals`, `hashCode` und `toString`.
