# String

> [!info] Kurz erklärt
> Unveränderliche (immutable) Zeichenkette. Wichtige Methoden: `length()`, `charAt(i)`, `substring(a, b)`, `indexOf`, `split`, `toUpperCase`, `trim`, `equals`, `compareTo`. **Vergleich immer mit `equals`, nicht mit `==`!**
