# XML

> [!info] Kurz erklärt
> Textbasierte Auszeichnungssprache mit verschachtelten Elementen `<tag attr="…">…</tag>`. **Wohlgeformt** heißt syntaktisch korrekt, **gültig** heißt zusätzlich konform zu DTD/Schema. In Java wird XML per JAXP (DOM, SAX) verarbeitet.
