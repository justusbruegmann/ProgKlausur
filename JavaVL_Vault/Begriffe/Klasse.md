# Klasse

> [!info] Kurz erklärt
> Eine **Klasse** ist der Bauplan für Objekte: Sie beschreibt Eigenschaften ([[Attribut|Attribute]]) und Verhalten ([[Methode|Methoden]]). Jede öffentliche Klasse steht in einer eigenen `.java`-Datei gleichen Namens.
