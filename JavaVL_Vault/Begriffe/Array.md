# Array

> [!info] Kurz erklärt
> Ein Array speichert eine **feste Anzahl** Elemente gleichen Typs: `int[] a = new int[10];` oder `int[] b = {1, 2, 3};`. Zugriff über Index `a[0]` … `a[a.length - 1]`, sonst `ArrayIndexOutOfBoundsException`. Arrays sind Objekte, also Referenztypen.
