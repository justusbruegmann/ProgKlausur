# if-else

> [!info] Kurz erklärt
> Bedingte Ausführung: `if (bedingung) { … } else { … }`; Ketten mit `else if` bilden Mehrfachverzweigungen. Vorsicht vor dem „bösen Semikolon“ `if (x); { … }`.
