# static

> [!info] Kurz erklärt
> `static`-Elemente gehören zur **Klasse**, nicht zu einem einzelnen Objekt: Alle Instanzen teilen eine Klassenvariable, und Klassenmethoden werden über den Klassennamen aufgerufen (`Math.sqrt(2)`). Sie haben keinen Zugriff auf `this`.
