# Zufallszahlen

> [!info] Kurz erklärt
> `Math.random()` liefert `double` in [0, 1); `new Random().nextInt(n)` eine Ganzzahl in [0, n). Damit füllt man Arrays, würfelt Lottozahlen oder erzeugt zufällige Farben.
