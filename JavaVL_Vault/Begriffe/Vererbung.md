# Vererbung

> [!info] Kurz erklärt
> Mit `class B extends A` übernimmt B alle (nicht-privaten) Attribute und Methoden von A und kann sie erweitern oder [[Überschreiben|überschreiben]]. Java erlaubt nur **Einfachvererbung** von Klassen; jede Klasse erbt letztlich von [[Object]].
