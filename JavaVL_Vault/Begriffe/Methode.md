# Methode

> [!info] Kurz erklärt
> Benannter Codeblock mit Parametern und Rückgabetyp (`void`, falls keiner): `public int add(int a, int b) { return a + b; }`. Instanzmethoden arbeiten auf einem Objekt, `static`-Methoden auf der Klasse.
