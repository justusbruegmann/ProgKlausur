# Abstrakte Klasse

> [!info] Kurz erklärt
> Mit `abstract` markierte Klasse, von der keine Objekte erzeugt werden können. Sie darf **abstrakte Methoden** ohne Rumpf enthalten, die Unterklassen implementieren müssen, und kann gemeinsamen Code und Attribute bereitstellen.
