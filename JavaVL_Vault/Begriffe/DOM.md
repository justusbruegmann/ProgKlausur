# DOM

> [!info] Kurz erklärt
> Das DOM lädt ein XML-Dokument als **Baum** von `Node`-Objekten in den Speicher (`DocumentBuilderFactory` → `DocumentBuilder.parse`). Navigation über `getElementsByTagName`, `getChildNodes`, `getAttribute`; Änderungen über `createElement`/`appendChild`. SAX liest dagegen ereignisbasiert als Strom.
