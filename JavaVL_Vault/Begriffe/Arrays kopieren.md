# Arrays kopieren

> [!info] Kurz erklärt
> `b = a` kopiert nur die **Referenz**, beide zeigen dann auf dasselbe Array. Eine echte Kopie gibt es mit Schleife, `System.arraycopy(src, srcPos, dest, destPos, len)`, `a.clone()` oder `Arrays.copyOf`.
