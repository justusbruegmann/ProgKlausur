# Comparable und Comparator

> [!info] Kurz erklärt
> `Comparable<T>` definiert die **natürliche Ordnung** einer Klasse (`compareTo`), `Comparator<T>` eine externe, austauschbare Ordnung (`compare(a, b)`, z. B. `Comparator.comparing(Person::getName)`). Rückgabe: negativ / 0 / positiv.
