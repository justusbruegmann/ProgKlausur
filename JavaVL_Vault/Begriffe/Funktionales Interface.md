# Funktionales Interface

> [!info] Kurz erklärt
> Interface mit genau **einer** abstrakten Methode (SAM), z. B. `Runnable`, `Comparator`, `ActionListener` oder `java.util.function.*` (`Function<T,R>`, `Predicate<T>`, `Consumer<T>`, `Supplier<T>`). Kann per Lambda implementiert werden.
