# Anonyme innere Klasse

> [!info] Kurz erklärt
> Klasse ohne Namen, die direkt bei `new` definiert wird: `new ActionListener() { public void actionPerformed(ActionEvent e) { … } }`. Typisch für Listener und Comparatoren; heute oft durch [[Lambda-Ausdruck|Lambdas]] ersetzt.
