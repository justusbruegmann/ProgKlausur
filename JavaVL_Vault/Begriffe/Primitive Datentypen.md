# Primitive Datentypen

> [!info] Kurz erklärt
> Java hat acht primitive Typen: `byte`, `short`, `int`, `long` (ganze Zahlen), `float`, `double` (Gleitpunkt), `char` (UTF-16-Zeichen) und `boolean`. Sie speichern Werte direkt, nicht als Referenz. Zu jedem gibt es eine [[Wrapperklasse]].
