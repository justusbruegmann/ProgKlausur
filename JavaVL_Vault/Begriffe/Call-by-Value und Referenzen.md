# Call-by-Value und Referenzen

> [!info] Kurz erklärt
> Java übergibt **immer Kopien**: bei primitiven Typen eine Wertkopie, bei Objekten eine Kopie der **Referenz**. Änderungen *am* Objekt (z. B. Array-Elemente) sind daher außen sichtbar, eine Neuzuweisung des Parameters dagegen nicht.
