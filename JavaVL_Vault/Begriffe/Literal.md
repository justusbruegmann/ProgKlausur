# Literal

> [!info] Kurz erklärt
> Ein **Literal** ist ein fest im Code stehender Wert, z. B. `42`, `42L`, `3.14`, `2.5f`, `'a'`, `"Text"`, `true`, `0x1F`, `0b1010`.
