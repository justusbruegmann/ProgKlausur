# Variable

> [!info] Kurz erklärt
> Benannter Speicherplatz mit festem Typ (`int x = 5;`). **Lokale Variablen** gelten nur im umgebenden Block `{ … }` und müssen vor der Nutzung initialisiert werden; Attribute (Instanzvariablen) gehören zum Objekt.
